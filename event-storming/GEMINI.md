## Spécifique Gemini CLI
- Sous-agents générés dans `.gemini/agents/`, commandes `/es-feature` et `/es-review` dans `.gemini/commands/`.
- Gemini CLI ne documente pas de réglage d'effort pour les sous-agents : l'effort cible est indiqué dans le prompt de chaque agent.
- Lancer Gemini CLI depuis le dossier `event-storming/`.
