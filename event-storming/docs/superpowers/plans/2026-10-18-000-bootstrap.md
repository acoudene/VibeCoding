# Sous-projet 000 — Bootstrap `event-storming` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Créer le projet autonome `event-storming/` avec son outillage (`npm run verify`), sa propre AI factory (copiée du socle `game-master`, préfixe `es-`), sa documentation fondatrice, ses ADR et sa CI, plus un premier morceau de domaine testé qui prouve que toute la chaîne fonctionne.

**Architecture:** Projet TypeScript hexagonal (`src/domain|application|infrastructure|presentation`), règles de couches vérifiées par dependency-cruiser. La factory (`factory/agents`, `factory/workflows`) est la source ; `scripts/sync-factory.mjs` génère les fichiers par outil (`.claude/`, `.codex/`, `.gemini/`, et `../.github/{agents,prompts,instructions}` préfixés `es-`). Aucun fichier n'est partagé avec `game-master`.

**Tech Stack:** Node 24, TypeScript 6, Vitest 5, Cucumber 13 (features en français), dependency-cruiser 18, tsx, Hono 4, Zod 4 — versions identiques à `game-master` (commit `7542b25`).

**Spec:** `event-storming/docs/superpowers/specs/2026-10-18-event-storming-design.md`

## Global Constraints

- Socle source : `git show 7542b25:game-master/<chemin>` (branche `feat/002-character-sheet`). Rien n'est lu depuis le working tree de `game-master` (absent de `main`).
- `event-storming/` n'importe, ne référence à l'exécution, ni ne génère aucun fichier de `game-master/`. Seule mention autorisée de `game-master` : la provenance du socle (ADR-0010, `docs/factory/README.md`) et le format de référence de `docs/domain/README.md` (ADR-0014).
- Technologies gratuites ou open source uniquement (ADR-0002).
- Docs, specs, prompts, features Cucumber en **français** ; code et identifiants en **anglais**.
- Préfixe des fichiers générés partagés à la racine du monorepo : `es-` (agents/prompts Copilot, commandes Claude/Gemini : `/es-feature`, `/es-review`). Fichier d'instructions Copilot : `.github/instructions/event-storming.instructions.md`.
- Le domaine n'importe aucune bibliothèque tierce (ni Yjs, ni xyflow, ni Hono).
- Pas d'appel LLM réel dans les tests ni en CI.
- `npm run verify` = `typecheck && test && test:bdd && test:arch && factory:check`, vert à la fin de chaque tâche à partir de la tâche 2.
- Commits Conventional Commits, scope `event-storming`, terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Le sync efface les fichiers générés de `game-master`** quand les deux branches seront fusionnées : le scan des fichiers obsolètes dans `.github/agents|prompts` doit se limiter au préfixe `es-`. → test dans la tâche 2 (fichier leurre `gm-*.agent.md` conservé).
